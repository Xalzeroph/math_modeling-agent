## 二、算法文档阅读

### 评价类算法
- **熵权法**: 基于数据离散程度的客观赋权，适用于数据驱动的综合评价
- **TOPSIS**: 基于正负理想解的距离排序，常与熵权法组合使用
- **CRITIC**: 考虑指标冲突性的客观赋权
- **灰色关联分析**: 小样本因素分析，可用于影响因素识别

### 预测类算法
- **灰色预测GM(1,1)**: 小样本预测，适合短期单调趋势
- **ARIMA**: 平稳时序预测，需要较大样本
- **线性回归/岭回归**: 多因素预测，适合STIRPAT模型参数估计
- **指数平滑**: 趋势+季节性时序预测

## 四、规律总结

### 方法选择规律
1. **评价类问题**：熵权法/CRITIC客观赋权 + TOPSIS排序 是 O奖论文的标准组合
2. **碳排放预测**：STIRPAT模型 + 情景分析 是学术界的标准方法
3. **模型递进**：简单模型(baseline) → 复杂模型 → 情景分析 是竞赛论文的成功模式
4. **多方法对比**：O奖论文普遍使用2-3种方法做对比，证明选择最优

### 论文章节规律
1. 摘要包含：背景1句+问题1-2句+方法2-3句+结果1-2句
2. 模型部分占总篇幅约40%，求解占20%，评价占20%
3. 注意细节：前提假设列表、符号定义表、灵敏度分析、S&W

### 对本题的指导
1. **问题1**：熵权法+TOPSIS（排序）+ K-Means（分类），参考CAFE框架
2. **问题2**：STIRPAT扩展模型（岭回归估计），参考Sun(2022)和Liu(2018)
3. **问题3**：基准/碳减排/加强碳减排三情景，用STIRPAT参数预测
4. **问题4**：基于实证结果的政策建议

### 常见错误避免
1. 不建指标体系直接用原始数据聚类 → 必须先构建综合评价指标
2. 预测模型不检验拟合优度 → 必须报R²、RMSE、MAPE
3. 缺少灵敏度分析 → 至少3个参数±20%扰动
4. 只用1种方法不做对比 → 至少2种方法对比（如熵权法+CRITIC对比）
