# 术语表 (Terminology) — C题 碳排放数据分析与研究

## 一、核心概念术语

| 中文名称 | 英文名称 | 缩写符号 | 定义/说明 |
|---------|---------|---------|----------|
| 碳排放 | Carbon Emission | CE | 二氧化碳为主的温室气体排放量 |
| 碳达峰 | Carbon Peak | - | 碳排放量达到历史最高值后开始下降 |
| 碳中和 | Carbon Neutral | - | 净零碳排放，排放量与吸收量平衡 |
| 碳排放强度 | Carbon Emission Intensity | CEI | 单位GDP产生的碳排放量 |
| 碳生产率 | Carbon Productivity | CP | 单位碳排放产生的GDP，与强度互为倒数 |
| 碳排效率 | Carbon Emission Efficiency | CEE | 投入产出角度评价碳排放效率 |
| 信息熵 | Information Entropy | H | 度量指标离散程度的信息量 |
| 贴近度 | Closeness Coefficient | C | TOPSIS综合评价得分，越接近1越优 |
| 熵权法 | Entropy Weight Method | EWM | 基于信息熵的客观赋权方法 |
| 双碳目标 | Dual Carbon Goals | - | 碳达峰(2030前)+碳中和(2060前) |
| 环境库兹涅茨曲线 | Environmental Kuznets Curve | EKC | 环境质量与经济发展呈倒U型关系 |
| 情景分析 | Scenario Analysis | - | 设定不同发展路径进行预测比较 |

## 三、模型相关术语

| 中文术语 | 英文术语 | 说明 |
|---------|---------|------|
| STIRPAT模型 | Stochastic Impacts by Regression on Population, Affluence, and Technology | 环境压力评估的随机回归模型 |
| TOPSIS | Technique for Order Preference by Similarity to Ideal Solution | 基于理想解相似度的排序方法 |
| 熵权法 | Entropy Weight Method | 基于信息熵的客观赋权方法 |
| K-Means聚类 | K-Means Clustering | 基于距离的划分聚类方法 |
| 灰色预测 | Grey Prediction Model GM(1,1) | 小样本灰色系统预测模型 |
| 岭回归 | Ridge Regression | 带L2正则化的线性回归 |
| 方差膨胀因子 | Variance Inflation Factor | VIF，多重共线性度量指标 |

## 四、省份分类

| 分类 | 说明 | 划分依据 |
|------|------|---------|
| 高排放-高效率 | 排放总量大但效率高 | 综合得分>0.7 |
| 高排放-低效率 | 排放总量大且效率低 | 规模得分高、效率得分低 |
| 中等排放-中等效率 | 各项指标居中 | 综合得分0.3-0.7 |
| 低排放-高效率 | 排放总量小且效率高 | 规模得分低、效率得分高 |
| 低排放-低效率 | 排放总量小但效率低 | 综合得分<0.3 |

## 五、情景定义

| 中文术语 | 英文术语 | 说明 |
|---------|---------|------|
| 基准情景 | Baseline Scenario (BAU) | 维持历史发展模式，无额外政策干预 |
| 碳减排情景 | Carbon Reduction Scenario | 适度政策干预，2030年前碳达峰 |
| 加强碳减排情景 | Enhanced Carbon Reduction Scenario | 强力政策干预，提前达峰并加速下降 |
