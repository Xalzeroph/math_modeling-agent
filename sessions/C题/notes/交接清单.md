# 交接清单 — 建模手→编程手

## 问题1：省域碳排放综合评价

| 项目 | 内容 |
|------|------|
| Problem # | 1 |
| Algorithm | 熵权法 + TOPSIS + K-Means聚类 |
| 选择理由 | 数据驱动、客观无偏、O奖论文标准方法 |
| Input format | 30省×5指标矩阵 (CSV)：碳排放总量、人均碳排放、碳排放强度、碳生产率、经济贡献协调度 |
| Output format | TOPSIS贴近度向量(30,)、排名(30,)、K-Means分类标签(30,) |
| Key params | 熵权法无参数；K-Means: n_clusters=4(最优聚类数) |
| Verification | [V-EVAL-1] 信息熵总和检验(0<e_j<1)；[V-EVAL-2] TOPSIS贴近度排序单调性验证；[V-EVAL-3] K-Means轮廓系数>0.3 |
| Visualization | 权重分布图、TOPSIS贴近度排名图、省域聚类地图(颜色编码)、雷达图(各组省会) |
| 数据来源 | 附件2 + 统计年鉴(GDP/人口) |

**数据预处理注意**:
- 附件2的30省Sheet读取总排放(TotalEmissions行)和Scope_1_Total列
- GDP/人口数据需从中国统计年鉴获取
- 负向指标(碳排放强度、人均碳排放)在标准化时需取倒数或反向处理

## 问题2：碳排放影响因素识别与预测模型

| 项目 | 内容 |
|------|------|
| Problem # | 2 |
| Algorithm | STIRPAT扩展模型 + 岭回归参数估计 |
| 选择理由 | 碳排放预测的学术标准方法，可解释性强 |
| Input format | 时序数据：碳排放量(Y)、人口(P)、人均GDP(A)、碳排放强度(T)、城镇化率(U)、第二产业占比(S)、煤炭占比(E) |
| Output format | 回归系数向量(7,)、R²、RMSE、VIF |
| Key params | 岭回归: alpha通过交叉验证选择 |
| Verification | [V-REG-1] R²>0.9；[V-REG-2] VIF诊断共线性；[V-REG-3] 残差正态性检验 |
| Visualization | 回归系数图、特征重要性图、拟合vs实际值散点图 |
| 数据来源 | 附件1(总量数据) + 中国统计年鉴(外部数据) |

**数据预处理注意**:
- 所有变量取自然对数后建模（STIRPAT对数形式）
- 变量间可能存在多重共线性，用VIF诊断
- 外部数据需自行收集（中国统计年鉴网站）

## 问题3：情景预测

| 项目 | 内容 |
|------|------|
| Problem # | 3 |
| Algorithm | STIRPAT扩展模型 + 情景参数外推 |
| 选择理由 | 与问题2模型一致，通过改变参数实现情景预测 |
| Input format | 各因素2026-2045年预测值（三情景） |
| Output format | 2026-2045碳排放预测（三情景）、碳达峰时间、峰值 |
| Key params | 各情景参数增长率（基准/碳减排/加强碳减排） |
| Verification | [V-PRE-1] 情景参数合理性检查（增长率非突变）；[V-PRE-2] 碳达峰时间合理性检查 |
| Visualization | 三情景预测对比图、碳排放强度变化图、达峰标注图 |
| 数据来源 | 问题2模型输出 + 情景假设 |

**情景参数延伸方法**:
- 基准情景：各因素按历史平均增长率外推
- 碳减排情景：碳排放强度年降速提升、煤炭占比加速下降、第二产业占比加速下降
- 加强碳减排情景：更强力的能源结构转型和产业升级参数
