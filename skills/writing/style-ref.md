# Style-Ref — 参考论文结构模仿

**执行角色**: 论文手  
**时机**: 论文撰写时（SOP Stage 7，可选）  
**输入**: 用户指定的参考论文（本地 PDF/TeX 或 arXiv ID）  
**输出**: `notes/style_profile.md`（仅用于结构指导）

---

## 定位

模仿一篇优秀论文的**结构风格**，不复制内容。仅在用户明确指定 `— style-ref:` 时启用。

---

## Step 1: 提取结构特征

从参考论文中提取：

| 特征 | 提取方法 |
|------|---------|
| 章节顺序 | 列出 section 标题和顺序 |
| 定理/公式密度 | 每 1000 字多少公式 |
| 图表密度 | 每 1000 字多少图 |
| 句子长度分布 | 平均句子长度（词数） |
| 段落长度 | 平均段落长度（句数） |

**不提取的内容**:
- 具体的 prose 表述
- 任何数字/结论
- 术语定义
- 参考文献条目

---

## Step 2: 生成 style_profile.md

```markdown
# Style Profile — 参考论文结构

**来源**: arXiv:2501.12345 "Example Paper Title"
**提取日期**: YYYY-MM-DD

## 章节结构
1. Introduction (2.1 页)
2. Related Work (1.8 页)
3. Preliminaries (1.5 页)
4. Method (4.2 页)
5. Experiments (3.3 页)
6. Discussion (1.2 页)
7. Conclusion (0.5 页)

## 风格指标
- 公式密度: ~18 公式/1000 字
- 图表密度: ~4 图表/1000 字
- 平均句长: 22 词（英文）/ 35 字（中文）
- 平均段长: 5.3 句

## 适用建议
- 该论文的章节分配适合方法创新类题目
- 公式密度较高，适合理论推导偏重的论文
- 实验章节占比大（~30%），如果我们的数据实验不多可缩减
```

---

## Step 3: 应用到论文

在 paper-plan 阶段参考 style_profile.md：
- 章节顺序借鉴（不是复制）
- 公式/图表密度作为参考目标
- 句子节奏模仿（不是复制句子结构）

---

## 严格禁止

| 禁止 | 说明 |
|------|------|
| 复制 prose | 不能复制参考论文的任何句子或段落 |
| 复制 claims | 不能复制参考论文的结论/发现 |
| 复制术语 | 不能复制参考论文的自创术语或命名 |
| 传给审稿手 | style_profile.md 不能传给审稿手（保持审查独立性） |
| 过度模仿 | 如果参考论文的结构不适合我们的内容，不要强行套用 |

---

## 输出

`notes/style_profile.md` — 论文手在写论文时参考，写完可删除。
