# Paper-Slides + Poster — 答辩展示材料

**执行角色**: 论文手  
**时机**: 论文编译完成后（SOP Stage 8，可选）  
**输入**: paper/main.tex + figures/  
**输出**: slides/（Beamer PDF + PPTX） / poster/（A0/A1 PDF + PPTX）

---

## Slides（答辩 PPT）

### Output
- Beamer LaTeX → PDF（正式投影）
- python-pptx → 可编辑 PPTX（方便学校模板调整）
- Speaker notes（每页讲稿）
- Full talk script（完整演讲稿）

### Slide 结构模板

| 页码 | 内容 | 时长 |
|------|------|------|
| 1 | 标题页（题目+队号） | 30s |
| 2 | 问题概述 | 60s |
| 3 | 模型选择（为什么选这个模型） | 90s |
| 4 | 模型详述（公式+图示） | 120s |
| 5 | 求解方法（算法流程图） | 60s |
| 6 | 结果展示（图表+关键数字） | 90s |
| 7 | 灵敏度分析 | 60s |
| 8 | 结论 | 30s |
| 9 | Q&A / 致谢 | — |

### 关键规则
- 每页 ≤5 行文字，字大字少
- 公式精简：只放最核心的 1-2 个
- 图占主位：2/3 面积是图
- 颜色和论文一致（蓝色主调）

---

## Poster（展示海报）

### Output
- LaTeX (tcolorbox + tcbposter) → A0/A1 PDF
- 可编辑 PPTX + SVG

### Poster 结构模板

```
┌─────────────────────────────────────────────┐
│  标题（大号加粗）         作者 / 队号       │
├─────────────┬──────────┬────────────────────┤
│ 问题背景    │ 模型     │ 结果（图+表）      │
│ (1/4 宽度)  │ (1/4)    │ (1/2 宽度)         │
│             │          │                    │
│ • 问题简述  │ • 公式   │ [大图占主位]       │
│ • 数据特点  │ • 算法   │                    │
│             │          │                    │
├─────────────┴──────────┼────────────────────┤
│ 灵敏度分析              │ 结论               │
│ [灵敏度图]              │ • 主要发现         │
│                         │ • 应用价值         │
│                         │                    │
├─────────────────────────┴────────────────────┤
│ 参考文献（小字）                              │
└─────────────────────────────────────────────┘
```

### 关键规则
- 标题大字（72pt+），正文 24-32pt，图表大
- 配色专业（蓝色主调，2-3 辅色）
- 读者流：左上 → 右上 → 右下（F 型阅读路径）

---

## Slides-Polish（幻灯片打磨）

生成 slides 后逐页审查：

| 检查项 | 标准 |
|--------|------|
| 字号 | 标题 36pt+，正文 20pt+（投影可读） |
| 颜色 | 蓝色主调，白底 |
| 公式 | 精简，无长推导 |
| 图表 | 占主要面积，标题清晰 |
| 页码 | 每页右下角 |
| CJK 字体 | PingFang SC / Microsoft YaHei |
| 代码（如有）| monospace, ≤10 行 |
