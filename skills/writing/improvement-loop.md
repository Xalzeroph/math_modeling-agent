# Improvement Loop — 论文多轮打磨

**执行角色**: 论文手  
**时机**: 论文初稿完成后（SOP Stage 8）  
**输入**: paper/main.tex + 所有 assurance audit JSON  
**输出**: 修改后的 paper/main.tex

---

## 目标

论文写完后，进行 3 轮审查→修正，提升论文质量。

---

## Round 1: 结构审查

### 焦点
逻辑连贯性、章节分配、论证链条

### 检查清单
- [ ] 摘要是否包含 5 个要素（问题/方法/模型/结果/结论）？
- [ ] 符号是否在首次出现时定义？
- [ ] 模型建立的顺序：假设 → 符号 → 公式 → 求解？
- [ ] 结果分析是否和问题一一对应？
- [ ] 章节之间是否有过渡句？
- [ ] 段落长度是否合理（5-8 行为宜，不超过 12 行）？

### 输出
结构改进建议列表，论文手修改。

---

## Round 2: 数字审查

### 焦点
与 claim_audit.json 联动，逐数核实

### 检查清单
- [ ] 读取 `assurance/claim_audit.json`，所有 `mismatch` 是否已修复？
- [ ] 每个数值的精度是否一致？（不要有的 2 位小数有的 4 位）
- [ ] 单位和量纲是否统一标注？
- [ ] 百分比和绝对值是否混淆？
- [ ] 图表中的数字和正文是否一致？

### 输出
数字修正建议列表，论文手修改。

---

## Round 3: AI 味审查

### 焦点
去机械化表达

### 扫描的 40+ AI 标记

| 类别 | 标记词 |
|------|--------|
| 过度强调 | 标志着、重要的里程碑、关键作用、奠定了坚实基础 |
| AI 高频词 | 此外、深入探讨、充分展示、值得注意的是 |
| 宣传性 | 突破性的、令人振奋的、前景光明 |
| 虚假范围 | 从...到...从...到... |
| 否定平行 | 不仅...而且... |
| 模糊归因 | 专家认为、观察者指出 |
| 公式化 | 挑战与展望 |

### 阈值
全文 AI 标记 < 5 处 → 通过。≥5 处 → 需修正后重新审查。

### 输出
AI 味位置列表 + 修改建议，论文手修改。

---

## 每轮流程

```
审稿手 persona 审查 → 产出建议列表 → 论文手修改 → 重新编译验证
```

**注意**: 审稿手只用论文手 persona 审查（不是审稿手 role），因为 improvement 是帮论文手打磨，不是 find-only。

---

## 关键规则

- Round 1-2-3 顺序执行，前一轮通过再下一轮
- 不自动修改论文——只产出建议
- 如果 claim_audit 有 FAIL → 先修复再进入 improvement
- 全部 3 轮通过后，才能进入 assurance gate
